How to use

三步完成配置与发布

全程约 5 分钟。详细图文步骤见仓库中的 docs/USAGE.md。

1

安装插件

从 Releases 页下载 main.js、manifest.json、styles.css 三个文件，放入仓库的 .obsidian/plugins/md-publisher/ 目录，然后在「设置 → 第三方插件」中启用。（社区插件商店审核中）

2

配置微信公众号认证

在「设置 → Markdown Publisher」中二选一：自动模式填入 AppID 与 AppSecret，并把本机 IP 加入公众号后台的 IP 白名单；手动 token 模式直接粘贴后台获取的 access_token，无需白名单。填完点击「测试连接」验证。

💡 没有 IP 白名单条件？选手动 token 模式，token 约 2 小时更换一次
3

预览、复制或发布

点击左侧边栏 📄 图标（或命令面板执行「打开排版预览」）打开实时预览，选好主题后：复制到公众号编辑器粘贴，或点发布直接存入草稿箱，也可打开草稿面板管理历史草稿。

Notes

发布前需要知道的几件事

账号需要已认证的公众号

  • 发布与草稿管理依赖微信草稿箱 API，需要已认证的服务号或订阅号
  • AppID / AppSecret 位于「公众平台 → 设置与开发 → 基本配置」
  • 个人订阅号完成认证后同样可用

安全凭证只存在本机

  • AppSecret 以明文保存在本机 Obsidian 配置中，请勿共享配置文件
  • 自动模式要求把本机 IP 加入公众号的 IP 白名单
  • 不想配白名单时，改用手动 token 模式即可

环境桌面端专属

  • 插件仅支持 Obsidian 桌面版（macOS / Windows / Linux）
  • 要求 Obsidian v1.0.0 及以上
  • 图片上传前会按 quality 0.8 默认压缩，超大图请提前瘦身

发布两种产物任选

  • 复制 HTML：粘进公众号编辑器手动微调后再发
  • 直接发布：进草稿箱，可在手机或网页端终审后群发
  • 发布前务必在预览面板确认排版效果
