# Markdown Publisher 使用说明

Markdown Publisher 是一款 Obsidian 插件，用于把 Markdown 笔记自动排版成微信公众号格式，并直接发布到公众号草稿箱：CSS 全部内联、本地图片自动上传、支持 KaTeX 公式与代码高亮。

> 环境要求：Obsidian 桌面版（macOS / Windows / Linux）v1.0.0 及以上；已认证的微信公众号（订阅号或服务号）。

---

## 一、安装插件

插件社区商店审核中，目前请手动安装：

1. 前往 [Releases](https://github.com/volcanicll/obsidian-md-publisher/releases)，下载最新版本的三个文件：
   - `main.js`
   - `manifest.json`
   - `styles.css`
2. 在你的 Obsidian 仓库中创建目录：`.obsidian/plugins/md-publisher/`
3. 把三个文件放入该目录。
4. 打开 Obsidian → 设置 → 第三方插件 → 关闭「安全模式」（如已开启）→ 在已安装插件列表中启用 **Markdown Publisher**。

## 二、配置微信公众号认证

打开 设置 → Markdown Publisher，在「微信公众号」区域选择一种认证方式。

### 方式 A：自动模式（推荐，需 IP 白名单）

1. 登录 [微信公众平台](https://mp.weixin.qq.com)，进入「设置与开发 → 基本配置」，获取 **AppID** 和 **AppSecret**。
2. 在同一页面的「IP 白名单」中，添加你本机的公网 IP（可在浏览器搜索"我的 IP"查询）。
3. 在插件设置中填入 AppID 和 AppSecret。
4. 点击 **测试连接**，显示成功即可。

⚠️ 注意：

- AppSecret 以明文保存在本机 Obsidian 配置文件中，请勿共享或提交你的 `.obsidian` 目录到公开仓库。
- 本机 IP 变化后（如换了网络），需要更新白名单。

### 方式 B：手动 token 模式（无需 IP 白名单）

1. 在插件设置中开启「使用手动 token」。
2. 登录公众平台，在「基本配置 → 开发者工具」等入口获取当前有效的 **access_token**（也可用公众号后台提供的调试工具生成）。
3. 将 token 粘贴进插件设置，点击 **测试连接** 验证。

⚠️ access_token 有效期约 **2 小时**，过期后需要重新获取并粘贴。

## 三、排版与发布

### 打开预览面板

- 点击左侧边栏的 📄 图标（打开排版预览），或
- 使用命令面板（`Ctrl/Cmd + P`）执行 **Markdown Publisher: 打开排版预览**。

预览面板实时渲染当前笔记，右侧可切换排版主题与代码高亮主题。笔记中的本地图片会直接显示在预览中。

### 三种输出方式

| 操作 | 用途 |
|------|------|
| **复制** | 复制带内联样式的 HTML，粘贴到公众号编辑器手动微调后再发 |
| **发布** | 弹窗中填写标题、作者、摘要、原文链接等，直接存入公众号草稿箱 |
| **草稿** | 打开草稿管理面板，分页查看、删除公众号草稿箱中的历史草稿 |

### 发布设置

在发布弹窗中可以设置：

- **标题**：必填，最多 64 字（微信限制）
- **作者**：可选，最多 8 字
- **摘要**：可选，最多 120 字，默认从正文开头自动提取
- **原文链接**：点击"阅读原文"跳转的地址
- **开启评论**：是否允许读者评论
- **仅粉丝可评论**：限制评论范围

超出微信字数限制时，发布前会收到明确提示。

发布后文章进入草稿箱，请在手机或公众平台网页端**终审排版**后再群发。

### 主题与样式

- 内置 **18 种排版主题**（Professional、Ayu Light、Terminal、Apple、Midnight、Newsprint、Neo-Brutalism 等）。
- 内置 **14 种代码高亮主题**（GitHub、Monokai、Dracula、Nord、One Dark 等）。
- 设置中可为两者指定默认值，并在「自定义 CSS」中覆盖任意主题规则（会内联生效）。

## 四、支持的内容格式

- GFM 表格、任务列表、脚注、删除线
- KaTeX 数学公式（行内 `$...$` 与块级 `$$...$$`）
- 代码块高亮（样式内联到公众号）
- Obsidian 图片嵌入语法 `![[图片.png]]` 与 `![[图片.png|300]]`（尺寸后缀会被忽略，代码块中不会误转换）

### 图片处理规则

- 本地图片自动压缩并上传到微信素材 CDN（默认 quality 0.8）
- GIF 保留动画；SVG 自动转为 PNG
- WebP / BMP / AVIF 等微信不支持的格式自动转为 PNG 后上传
- PNG 保留透明通道；需要转 JPEG 压缩时自动铺白底，不会出现黑底
- 同一图片在文中出现多次时只上传一次，复用微信 URL

## 五、常见问题

**Q：测试连接失败？**
检查 AppID/AppSecret 是否正确、本机 IP 是否已加入白名单（自动模式），或 token 是否已过期（手动模式）。

**Q：发布报错 IP 不在白名单？**
自动模式要求本机公网 IP 在白名单内；换网络后 IP 会变。可改用手动 token 模式绕过。

**Q：为什么没有移动端？**
插件依赖桌面端能力，目前仅支持 Obsidian 桌面版。

**Q：发布的文章样式错乱？**
公众号编辑器限制较多，个别标签会被过滤。先在预览面板确认效果，必要时用「自定义 CSS」调整，或复制 HTML 粘贴后在编辑器中微调。

**Q：图片上传失败？**
确认图片可被 Obsidian 访问（本地路径或可下载的 URL），过大图片先手动压缩。
